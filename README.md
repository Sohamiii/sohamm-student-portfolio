## Deploy on Vercel using GitHub
1. Extract this ZIP on your computer.
2. Sign in to GitHub and create a new repository, for example `sohamm-student-portfolio`.
3. Upload `index.html` and `README.md` to the repository root and commit the files.
4. Sign in to Vercel using GitHub.
5. Choose **Add New → Project**, then import your `sohamm-student-portfolio` repository.
6. For a plain HTML website, no framework or build command is required. If Vercel asks, leave the framework preset as **Other**, leave Build Command empty, and use `./` as the output directory (or the root directory default).
7. Click **Deploy**. When it finishes, Vercel will provide a live `*.vercel.app` URL.
8. Open the live URL on phone and computer to check layout and email link.

## Updating later
Edit `index.html`, commit/push the change to GitHub, and Vercel will redeploy automatically when the repository is connected.
